A cosa serve Bootstrap?

Bootstrap è una libreria CSS/JS che facilita la creazione di pagine web responsive e con componenti pronti (grid system, bottoni, navbar, form, card, ecc.). Permette di avere layout che si adattano automaticamente a diversi schermi senza scrivere CSS da zero.

Cosa devi importare per creare una pagina web con Bootstrap?

Per usare Bootstrap 5, importa il CSS di Bootstrap (tipicamente via CDN) nell'`.


<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.1.3/dist/css/bootstrap.min.css" rel="stylesheet">

<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.1.3/dist/js/bootstrap.bundle.min.js"></script>

Cos’è un CDN? Che vantaggi comporta rispetto a scaricare bootstrap sul tuo sito?

Un CDN (Content Delivery Network) è una rete di server distribuiti geograficamente che ospitano file statici (come CSS/JS). Vantaggi:

  • Tempi di caricamento più rapidi per gli utenti (file serviti dal nodo più vicino).
  • Caching condiviso: se l’utente ha già caricato lo stesso file da quel CDN su un altro sito, non lo scarica di nuovo.
  • Riduce il traffico sul tuo server e semplifica l’aggiornamento delle librerie.

Svantaggio: dipendi da un servizio esterno (se il CDN è down o sei offline il file non si scarica).

A cosa serve questo attributo del tag meta? content="width=device-width, initial-scale=1"

Questo meta dice al browser di impostare la larghezza dell'area di visualizzazione (viewport) uguale alla larghezza del dispositivo e di iniziare con uno zoom 1. Serve a rendere la pagina responsive sui dispositivi mobili: senza di esso il layout “bootstrap” non si adatterebbe correttamente nei telefoni.

Differenza tra Container e Container Fluid

Container: .container è un contenitore con larghezze massime predefinite che cambiano a seconda del breakpoint (ha margini laterali). Container Fluid: .container-fluid occupa l'intera larghezza disponibile (100%) indipendentemente dal breakpoint.

Prova pratica: crea anche `BTS_1.1.1.html` con `container-fluid` e apri entrambi i file per ridimensionare la finestra del browser.
